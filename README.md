# iGuzzini UK Competitor Intelligence

Technical pilot for collecting **public** architectural lighting competitor news about ERCO, Fagerhult, Zumtobel, XAL, TRILUX and Delta Light.

This is a public research prototype, not iGuzzini's private marketing workspace. **Do not publish confidential strategy, customer information, credentials or private analytics here.**

A GitHub Actions job will collect public Google News RSS discoveries, mark them as **unverified**, and publish the feed via GitHub Pages. It must be checked for accuracy before strategic use. The main Marketing Hub V85 is unchanged.
